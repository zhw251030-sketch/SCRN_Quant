# Activation Quantization Configs

This directory stores reproducible configuration files for SCRN-BRECQ activation
quantization diagnostics and follow-up experiments.

Planned configuration groups:

- `E001`: activation quantizer diagnostics.
- `E002`: positive activation scale constraints.
- `E003`: activation initialization coverage and learning-rate sweeps.
- `E004`: quantizer placement and sensitivity analysis.
- `E005`: outlier handling and activation quantization granularity.
- `E006`: activation reconstruction targets and teacher-model variants.

Keep files in this directory small and text-based. Do not place checkpoints,
datasets, generated arrays, logs, or run outputs here.
